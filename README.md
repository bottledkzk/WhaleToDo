# WhaleToDo

把待办、时间和行动放在一起。

WhaleToDo 是软件工程团队项目：以 Android 应用为主要客户端，配套下载介绍页与后续账户服务。优先把快速记录、直观计划、自动协调、提醒和打卡做成顺手的日常流程，再逐步加入 AI 辅助与自主分享。

## 当前阶段

当前Android客户端0.4.0：在快速记录、WorkTime、手动/自动安排、待办日程、月历和打卡基础上，增加事务类型、账户分区会话/历史、只读日程助手、Working计时、受授权的编辑提案预览、Token/k用量和统一权限提示；提供8种分享样式预览与鲸鱼头像。规则33项，设备26个用例分批通过；正式调试包保留原五表数据升级到Room v3。

静态官网、PG16和上一阶段独立AI网关已有部署。当前APP默认访客桥接，正式登录/签到/网络仍待Weiding接入；本轮新增计量与编辑策略只在隔离数据库/服务验证，未切换现网。图片导出、相册/相机、社交平台与积分模板试用服务仍由Weiding实现。提示词/账户权限建议、桥接接口与真实验证边界见[AI助手接入](doc/Bottledkzk/2026-10-24-AI助手设计与接入.md)。

团队先读 [项目方案书](doc/All/项目方案书.md)、[目标功能文档](doc/All/目标功能文档.md)、[分工与协作方案](doc/All/分工与协作方案.md) 和 [账户、AI积分与安全方案](doc/All/账户-AI积分与安全方案.md)。

## 目标能力

- 快速记录：最少字段创建待办，支持稍后补全、搜索、标签和分阶段目标。
- 直观 Todo 分布：列表、日／周时间线、月日历、负荷与截止概览。
- 自动协调：在空闲、忙碌、截止和工作量约束下安排，临时插入后保留已完成与固定安排。
- 提醒与打卡：通知、完成、自评和复盘，不把计划当完成。
- AI 辅助：登录并使用服务端积分额度，会话、受控提案、日记与分享短句，确认后才修改记录。
- 自主分享：Android 分享面板、可保存的计划／打卡图片，默认隐藏私人字段。
- 账户和网站：登录注册、账户隔离、同步、签到积分、VIP与简化支付；下载页提供实际版本信息。

完整范围、优先级和验收见 [目标功能文档](doc/All/目标功能文档.md)。

## 仓库结构

```text
WhaleToDo/
├── app/          Android 客户端
├── core/         可独立测试的业务规则
├── web/          下载介绍页
├── doc/
│   ├── All/      团队共用基线，一般通过评审才修改
│   ├── Bottledkzk/  成员面向团队的汇报
│   └── Weiding/     成员面向团队的汇报
├── build/        构建产物说明，生成文件不直接入库
├── env/          可分享的环境配置和示例
└── script/       配置、构建和检查脚本
```

本地 SDK、IDE、设备镜像及个人日志放在仓库外。真实账户凭据、签名库和手机数据不进入公开 Git。
