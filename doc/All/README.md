# 团队共享基线

当前版本0.2，依据2026-10-22项目发起人明确的账户／AI／积分／支付和两人分工要求修订。一般不修改，范围或接口发生变化时通过PR更新。

建议阅读顺序：

1. [项目方案书](项目方案书.md)：整体目标、两人方向和阶段范围。
2. [目标功能文档](目标功能文档.md)：完整功能、优先级与验收。
3. [分工与协作方案](分工与协作方案.md)：主责、交接、Git与设备协作。
4. [账户、AI积分与安全方案](账户-AI积分与安全方案.md)：登录门槛、签到、VIP、演示支付和服务器保护。
5. [接口与数据契约草案](接口与数据契约草案.md)：未来API／数据边界，需双方冻结后实现。
6. [架构与技术栈](架构与技术栈.md)、[迭代与验收](迭代与验收.md)、[环境与设备](环境与设备.md)。
7. [协作约定](协作约定.md)与[答辩准备](答辩准备.md)。

本轮收尾和方案修订之后等待任务安排，不自动开始下阶段。文档中的设计能力与已编译、模拟器、真机、真实服务状态分别记录。
