# 协作约定

版本0.5，2026-10-31。职责已由项目发起人明确，以 [分工与协作方案](分工与协作方案.md) 为准。本文不再使用“全部分工待定”的旧口径；当前交付、追加职责及待补证据以最新验收为准，不以旧“资源未齐”说明覆盖上线事实。

`doc/All`为团队共用基线，一般不改；范围、接口或安全规则变化通过PR评审并更新版本。`doc/Bottledkzk`与`doc/Weiding`存各自对团队公开的材料；不伪造对方完成记录。外层report／plan／env等个人内容不加入团队仓库。

主分支main保持可构建，短功能分支后评审合并；共享数据库迁移、API契约、统一错误和部署配置由双方检查。主责不代表独占决定涉及另一模块的字段；改动前说明兼容／迁移方法。

工作包记录功能ID、主责、协作方、输入输出、依赖、验收、状态与证据。建议PR说明：问题与结果、涉及模块、验证、截图和限制。成员各自提交理解并验证过的代码，不空提交、倒填日期或拆分无意义改动凑次数。

不推送真实Key、令牌、签名库、个人数据、SDK缓存与测试账号。GitHub用户名尚未核实前不邀请同名账号，不在未获明确授权时给外部人员发消息。分享仓库链接由用户自行完成。
