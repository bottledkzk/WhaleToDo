# 答辩准备

目标是讲清软件如何工作、为什么这样设计，以及证据如何支持结论。

## 演示主线

1. 快速添加事项并补充截止和工作量。
2. 配置空闲或忙碌，生成计划，解释未排量。
3. 插入紧急事项，对比保留与移动块。
4. 完成、自评、重启，展示真实持久化。
5. 按实际完成范围展示AI提案、分享和账户；未接通部分只讲设计，不伪造演示。

## 代码讲解点

- Compose状态→ViewModel→Repository→Room的数据流。
- core调度输入、区间并集／扣除、预算、排序、保护块和输出。
- 事务提案与失败回滚；模型输出为什么不能直接落库。
- 通知渠道、权限、后台限制和取消更新。
- 身份隔离、同步冲突、凭据与分享隐私。
- 一个真实遇到的问题、复现测试、修复和提交差异。

每位成员选定能讲清的核心代码和测试，不只背技术名词。代码引用用文件路径和提交SHA；演示包绑定版本和校验值。提交记录用于说明迭代与协作，不代替功能验收。
