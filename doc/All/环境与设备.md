# 环境与设备

版本0.5，2026-10-31。标准API36模拟器为共同基线；Bottledkzk小米14 Pro Android16完成公开包基础流程和0.5.4日记增量，Weiding本人矩阵待补录。

## 已有开发基线

Windows独立SDK目录和项目进程环境。仓库env只放配置，实际IDE／SDK／AVD／Gradle缓存放仓库外。固定JDK21运行、Java17字节码、Gradle8.13、AGP8.13.2、Kotlin2.2.21、Compose BOM2025.10.01、Room2.8.3，compile／target SDK36、minSDK26。

首轮本机工具：Android Studio2026.2.1、命令行工具23.0、模拟器37.2.12、API36 Google APIs x86_64镜像。平台与IDE下载经过官方校验，构建和验证记录见成员报告。各自安装版本以env配置及实际日志为准，不依赖“最新版”字样。

## 模拟器与真机

共同配置：API36标准手机、4GB、4核、硬件加速。各自创建独立设备，复现问题优先相同镜像。低版本、窄屏、大字体、暗色、手势、横屏／大屏按矩阵逐步验证，不必同时启动多台。

真机使用当前系统，不能按手机型号猜测系统版本。持有人开启USB调试并确认电脑授权，仅当ADB显示device才认为连接成功；不清数据、不解锁引导程序、不导出私人照片或账户。通知／后台／电池限制、相机、相册、目标分享应用分别验证。

## 服务器与域名

官网与API已使用HTTPS8443，数据库仅回环、账户和AI分进程；Node24 / PostgreSQL16与十条前向迁移，凭据隔离、备份与临时库恢复分别验证。Bottledkzk维护部署发行，Weiding配合认证网络；持续清理未启用，未宣称自动异地容灾。全部充值MOCK，无真实收款。
