# 环境与设备

## 基线

Windows开发，使用独立SDK目录和项目脚本设置进程环境。可分享配置在仓库env，本地SDK、IDE、AVD与Gradle缓存在仓库外。不要把local.properties、设备序列号、签名库或用户数据提交。

首轮拟定API26起支持、compile／target SDK36、JDK21运行Gradle并输出Java17字节码。AGP、Gradle、Kotlin、Compose与Room版本在toolchain配置固定，安装和官方构建通过后再记录实测状态。

## 模拟器

先创建一个API36标准手机，4GB内存，使用硬件加速；不需要复制真实手机全部规格。后续增加低版本、窄屏、大字体、暗色、横屏及大屏配置，先按场景验证而非同时启动多台。

## 小米14 Pro

使用设备当前系统，不按出厂型号猜测版本。开启开发者选项和USB调试，连接后在手机确认电脑RSA授权；仅当ADB返回device才认为连接成功。也可使用Android11以上的无线配对流程。设备上的授权和锁屏操作须由持有人完成。

只安装独立应用ID的调试包，不清空手机，不解锁引导程序，不导出私人照片、账户和备份。通知、精确提醒、电池优化和后台限制在实际系统中逐项核对。连接准备完成不等于真机验收通过。
