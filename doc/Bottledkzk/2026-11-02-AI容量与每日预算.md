# AI 容量与每日预算

## 运行策略

- 调用次数和并发不设配额，不恢复旧的每分钟、每日次数和两请求限制
- 全站每日输入与输出合计最多 10,000,000 token，以 Asia/Shanghai 的自然日统计
- 单次输出配置为 393,216 token，这是在用 Flash 与 V4 Pro 的供应商最大输出值；1,048,576 是上下文窗口容量。依据：[官方模型元数据说明](https://api-docs.deepseek.com/api/list-models/)，部署前另通过真实 `/models` 只读查询核对
- 实际输出空间取模型上限、剩余日预算和账户积分可覆盖空间中的较小值。不会要求每个账户都持有最大输出的全部积分才能发起短任务
- 成功按真实 token 结算，未用预占返还；失败不扣积分，但已产生的供应商用量仍计入全站日预算
- 正在执行和结果未知的请求按预占量占用日预算；跨午夜的未决请求继续保留预占，完成时按结算日计实际量，不因换日遗漏正在消耗的请求
- 同编号重放优先返回已有回执，达到预算后仍可查询与重放，不重复调用模型

数据库事务只串行处理短时预占与结算，模型调用在事务外执行。日预算按输入和输出总量计算，不能仅统计用户实际扣分的成功请求

## 返回与存储

响应文本从 64 KiB 扩为 4 MiB，供应商 JSON 响应读取上限为 8 MiB，保持 UTF-8 字节检查，不截断为成功。提案条数、明确授权、预览与采纳契约保持不变。输出 token 参数是上限，不强制生成长文；既有网络超时与未决恢复仍适用

发布前完成备份及隔离恢复演练，确认旧迁移校验值、原记录摘要保持；随后应用追加迁移，更新 `AI_MAX_OUTPUT=393216`、`AI_GLOBAL_DAILY_TOKENS=10000000`，只重启 AI 网关。失败时回退网关与配置，放宽后的约束可保留，避免对已保存的长回复执行缩短约束

账户 API、支付配置和 APK 不随本次网关升级。旧版 APK 可继续使用本次接口；大回复传输与存储回归独立验证，不用短模型调用证明极限吞吐
