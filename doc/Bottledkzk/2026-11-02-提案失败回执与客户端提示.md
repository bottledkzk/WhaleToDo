# 提案失败回执与客户端提示

已完成的课表冲突校验曾返回 HTTP 503，公开客户端将其识别为服务故障，未显示回执中的具体冲突说明。现在这类业务结果返回 HTTP 200，回执仍保持 `status=failed` 和 `MODEL_OUTPUT_INVALID`，客户端直接展示具体原因

- 首次提交、同编号重放和查询返回一致的已完成回执，重放不再调用模型
- 失败沿用账本释放预占的分支，不结算成功积分；未知结果继续保留待查询状态
- 真正的上游故障仍为 503，结果未知仍为 202
- 图片解析提示使用当前公开客户端支持的文案前缀，无需升级 APK
- 沿用 v16 的周次上下文、逐项冲突筛选和 16,384 token 输出预算

手机用户已反馈原课表出现课程预览；这确认了预览入口，尚不代表该份课表已经采纳写入
