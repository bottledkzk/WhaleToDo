## 能力与执行边界

| 能力 | 实现与验证 |
| --- | --- |
| 对话、计划建议、复盘 | 六种固定模式，历史与日程始终作为不可信用户数据；截止、重要度、可见数量和本地时间由代码整理，部分日程明确标记 |
| 日记 | 指定日期、时区、所属账户的真实打卡作为完成事实；不把预计工时、旧完成状态当成当天实际耗时；草稿仍须预览和确认保存 |
| 分享配文 | 八种风格，模型返回严格 JSON；网关转换为恰好三条、每条不超过 50 个 Unicode 字符的可编辑短句 |
| 编辑提案 | 仅改名、分类、移动三个白名单动作；明确目标和时刻的移动由代码解析时区、编译时间戳，模型不能自行决定约束；校验对象、完成/固定/开始状态、工时、截止、可用时间和冲突；模型不能设置积分、VIP 或直接执行 |
| 采纳、拒绝、意见 | 原快照预览后才在本地事务采纳；重复采纳与旧快照被拒绝；意见使用新请求重新生成，原提案不再可用 |
| 失败恢复 | 原 UUID 查询，不因断网/429/5xx 重发；明确失败释放，未知保留；已知用量但格式无效/截断的结果退还积分，实际模型 token 仍计入安全限额 |

服务器对日程副本的校验不能代替客户端的账户、权限、最新快照与事务门禁。任意新建、删除、改截止/工时、自动采纳和账户工具均不在编辑白名单内；只读模式不会自行切换为编辑

## 真实模型证据

`script/real-ai-acceptance.mjs` 使用合成事项直接调用真实模型，覆盖六模式、八配文风格、固定/完成/越权/注入、实际客户端 agendaText、意见重生成、5/15/50/100 事项及长历史。默认只算预算，显式 `--run` 才调用；逐次保存不可覆盖的回执，receipt 用临时文件原子替换。凭据只由服务器 systemd LoadCredential 提供

这类测试不使用生产账户余额，不生成登录会话，不冒充 APP 完整闭环。日记与分享仍是待用户核对的草稿，自动检查通过不等于自然语言永远无误

## 平均 0.5 积分的试算

校准集选正常用户场景，排除身份询问、注入、资料缺失与禁止修改请求；将“初始编辑 + 一次意见”作为一个完整任务，保留失败尝试用量并纳入一次匹配的成功恢复；额外工程确认重复不冒充新增用户任务，确认采纳是本地操作，不再调用模型。第七轮正常场景加最终必要恢复的 97 次正常调用组成 90 个完整任务样本，实耗 140,606 token，平均 1562.29 token/任务

据此试用 **3,200 token = 1 积分**，按单个账户累计结算的本轮平均为 **0.489 积分/任务**。这是合成工作负载的初始校准，长上下文、模式占比与意见次数变化都会改变均值；并非每次固定扣 0.5，也不等于供应商现金价格

钱包继续保留整数：同一账户、同一冻结兑换率和累计规则下，本次扣分为 `ceil(累计成功 token / rate) - 以前已结算积分`，因此可出现 0 或 1 积分。小请求不重复收最少 1 积分，余量跨日保留。先按保守上界预占，终态退差额；不同账户不共享余量，旧请求不改价，未知请求不退款或自动重试

已知用量但内容不可用时，服务端以 `MODEL_OUTPUT_INVALID` 失败回执释放全部积分，保留真实输入/输出/总 token，安全限额仍计算这些成本；其用量不进入成功累计桶。`/ai/usage` 的 `billing_bucket_tokens` / `billing_bucket_points` 是当前费率成功桶的精确十进制字符串，在线验收工具据此核对 0 积分回执和钱包差额，复用原 ID 恢复

## 迁移与发布

只追加 `202610290001_agent_billing`，新增每请求冻结的 `billing_strategy` 与累计查询索引；旧六条 SQL 不变，旧行默认 `per_request`。AI 角色仍无读取 point_ledger、密码哈希或 DDL 权限；累计数据来自它已可读取的 ai_requests，结算先锁同一钱包，防并发重复跨过整数边界

配置示例与新运行时默认采用 `AI_TOKENS_PER_POINT=3200`、`AI_BILLING_STRATEGY=cumulative_tokens`。保留显式 `per_request` 回退开关。已有私有环境若显式覆盖费率，发布时必须单独核对；不能因代码默认改变就声称线上已调价

历史发布记录（不得作为当前执行步骤）：当时 full/gateway 发布包均包含七条迁移与原始校验表，gateway 仍禁止启动账户 API。发布需冻结已审提交，先备份并在服务器新临时恢复库演练六→七，核对旧数据、未知预占、权限和账本后，再按门禁追加生产迁移；新 schema 留作向后兼容回退，不自动恢复旧 dump。真实凭据和备份不入包或下载到本机
