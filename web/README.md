# WhaleToDo 下载页面

原生静态 HTML/CSS/JS，无第三方字体、分析器、账户表单或密钥。页面中的收集箱是当页交互示意，不上传、不持久化，不替代 Android 应用。

本地预览：在本目录运行 `python -m http.server 4173` 后访问 `http://localhost:4173`。网站可直接部署到任意静态服务器。下载按钮链接真实 GitHub Releases 列表；只有发布页实际存在的附件才可下载。

独立预览部署不承担应用账户服务。未来购买域名与部署身份服务时，另做 HTTPS、账户隔离、服务端安全和恢复验证。

官网已部署到`http://whaletodo.top`，HTTPS源站配置在8443，公网状态见[官网部署与团队接入说明](../doc/Bottledkzk/2026-10-23-官网部署与团队接入说明.md)。部署配置见`env/nginx/`。官网为静态内容，账户、同步、AI等后端仍未上线；当前没有公开APK Release。
