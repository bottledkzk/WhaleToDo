# WhaleToDo 下载页面

原生静态 HTML/CSS/JS，无第三方字体、分析器、账户表单或密钥。页面中的收集箱是当页交互示意，不上传、不持久化，不替代 Android 应用。

本地预览：在本目录运行 `python -m http.server 4173` 后访问 `http://localhost:4173`。网站可直接部署到静态服务器。当前页面准备指向 0.5.2-preview.1 的固定版本附件；只有签名包完成安装／升级和发行读回核验后才部署本页。

构建和发布见 [发行流程](../release/README.md)。将四个经校验的发行附件复制到 `downloads/v0.5.2-preview.1/`，与网页一起部署到全新的版本目录。`release.json` 驱动大小和 SHA256 展示；附件部署前不切换官网软链接。下载目录是构建产物，不加入 Git。

## 自有域名部署

官网入口为 `http://whaletodo.top`，HTTPS 源站使用 8443；现有 443 服务保留。生产网关与 APP 网络桥接的验收分别记录；页面明确标注当前 APK 的账户与在线 AI 尚未接通。上线状态以实际 HTTP 与 Release 附件回执为准。
