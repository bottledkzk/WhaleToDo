# WhaleToDo 0.5.3-preview.1

独立签名预览版，包名 `io.whaletodo.app.preview`，versionCode 10，Android 8.0+。

- 纳入已合并的账户与 AI 网络桥接：认证刷新、账户隔离、真实网关提交及原请求 ID 查询。
- 提醒按账户归属调度，失败登录、退出及过期回调不会重新启用旧账户提醒。
- 查询临时限流或服务不可用时保留原请求，不自动换新 ID 调用模型。
- 本地记录、受保护排程、预览日历及本地日记保持可离线使用。
- 包含 Room 6 本地账户分区与升级迁移，修复已使用过的 Room 5 部分索引迁移验证。
- 修复透明 PNG 导出；选中配文进入预览、导出图片和分享文字，连续导出保留旧 URI。
- 修复验证码成功后错误提示“邮件未接入”，以及签到、退出等空 POST 的 JSON 格式。

账户 API、六条生产数据库迁移和新版 AI 网关已有独立发布回执，见仓库文档《2026-10-28-生产账户与发行状态交接》。真实邮件到达、手机注册/登录/签到、AI日记/配文质量与计费仍逐项验收；配置文件、健康页或合成测试不能替代。客户端同步引擎尚不包含在此包。
