# WhaleToDo 0.5.3-preview.1

独立签名预览版，包名 `io.whaletodo.app.preview`，versionCode 10，Android 8.0+

- 账户：邮箱注册、验证码重发倒计时、登录与密码重置、头像、昵称、Motto 和七日签到
- 日程：访客记录和账户分区保留，保护固定时段的自动安排、待办与预览日历
- 助手：真实网关对话、日记和分享配文；VIP 编辑先生成提案，再由用户 Accept 写入日程，支持批量安排、跨日和已有时段调整
- 恢复：响应不确定时查询原请求 ID，不重新创建模型调用；账号切换隔离请求、提醒与支付回执
- 同步：个人资料和日记随账户同步，助手会话仅保存在本地；VIP 日程仅在主动备份、兼容或覆盖操作时上传/同步
- 充值：六档积分与 VIP、在线收银台、确认/取消及重开恢复；全部为 MOCK 模拟支付，无真实扣款，权益用于本项目演示
- 分享：透明 PNG、配文预览与图片/文字导出，修复 Android 相册/相机头像入口
- 升级：Room 6 分区与索引迁移，同签名 0.5.2-preview.1 可保留数据覆盖升级；与原体验应用并存，两包数据独立

服务端 full 发行包包含十条迁移，按原八条后追加商品目录和六档迁移；保留已有自定义商品及订单快照。部署前备份、临时恢复升级演练和权限检查，部署后分别核对 API、真实模型、持久账本及恢复回执
