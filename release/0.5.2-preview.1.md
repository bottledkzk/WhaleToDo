# WhaleToDo 0.5.2-preview.1

首次公开签名预览版，Android 8.0+。这是本地功能预览，不代表账户、在线 AI、通知、图片分享、邮件或支付已全部接通。

- 快速记录、待办与日程搜索、手动固定时段、保护既有安排的自动排程。
- 保留预览日历和活动月历；取消独立日／周／月／学期切换与长期／多阶段目标的开发计划。
- 助手模式、会话和授权提案界面；本地日记、主题、资料、Working 时间与时区设置。
- 独立包名 `io.whaletodo.app.preview`，名称“WhaleToDo 预览”，使用固定发行签名，不含调试权限、供应商 Key 或测试账户。

## 安装和升级

下载 APK，按手机提示允许本次安装来源。校验 SHA256SUMS.txt 与 release.json 中的 SHA256、包名、版本和签名证书摘要。预览版可与原调试体验包并存；两者的数据分别保存，不会自动迁移。以后用同签名、更高版本号的预览 APK 覆盖升级，保留本预览版数据。不要通过卸载旧应用来解决签名冲突。

## 已知限制

当前 APK 的账户网络桥接与 AgentBridge 尚未接入，不能在 APP 内登录、签到或调用在线 AI。服务端生产网关发布与 APP 接入分开验收。提醒权限、媒体导出、系统分享和邮件投递仍按团队分工接入；充值与 VIP 页面不是实际收款入口。未完成双方真机验收。

固定版本附件位于本 Release；预发布不使用 `/releases/latest/download/`。
